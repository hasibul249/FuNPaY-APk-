FuNPaY v1.2 - Android অ্যাপ (Capacitor + ফ্রি Supabase + ফ্রি GitHub)
=====================================================================
নতুন: পিসি লাগবে না, আপডেটে APK লাগবে না (OTA), ৬ ডিজিট PIN, ফিঙ্গারপ্রিন্ট/ফোনের স্ক্রিন লক দিয়ে আনলক।

অটো আপডেট কীভাবে চলে
--------------------
APK ইনস্টল হবে শুধু একবার। এরপর আপনি GitHub এ কোড বদলালেই ১-২ মিনিটে সবার অ্যাপ খুললে "নতুন আপডেট এসেছে" পপআপ আসে।
"আপডেট করুন" চাপলে নতুন কোড ডাউনলোড হয়ে অ্যাপ নিজে নতুন ভার্সনে খুলে যায়। আনইনস্টল, নতুন APK, প্লে স্টোর, কিছুই লাগে না।
আপডেটে কী লেখা দেখাবেন তা update-notes.txt এ লিখুন। ভার্সন নম্বর নিজে নিজে বাড়ে।
নতুন কোড ভাঙা থাকলে অ্যাপ নিজে আগের চালু ভার্সনে ফিরে যায়।
OTA দিয়ে বদলানো যায়: দেখতে (ডিজাইন), অ্যানিমেশন, লেখা, লজিক, সার্ভিস। নতুন নেটিভ ফিচার (নতুন প্লাগইন, যেমন নোটিফিকেশন) যোগ করলে শুধু তখন নতুন APK লাগবে।

ধাপ ১) ফ্রি ব্যাকএন্ড (Supabase), একবারই
-------------------------------------------
১) supabase.com এ ফ্রি অ্যাকাউন্টে "New project" বানান।
২) Authentication > Sign In / Providers > Email: "Confirm email" বন্ধ (OFF) করে Save।
৩) SQL Editor এ backend/setup.sql এর পুরোটা পেস্ট করে Run।
৪) Project Settings > API থেকে Project URL আর anon (Publishable) key কপি করে www/js/app.js এর ওপরের SUPA_URL ও SUPA_KEY তে বসান।

ধাপ ২) পিসি ছাড়া GitHub এ তোলা ও APK বানানো
--------------------------------------------
১) github.com এ Public repository বানান (যেমন funpay)।
২) repository পেজে Code > Codespaces > "Create codespace on main" (ফ্রি, ব্রাউজারেই চলে, ফোনেও)।
৩) Codespace এর বাঁ পাশের ফাইল তালিকায় FuNPaY-App-v1.2.zip টেনে আনুন (বা Upload)। নিচের টার্মিনালে:
     unzip FuNPaY-App-v1.2.zip
     cp -r FuNPaY-App/. . && rm -rf FuNPaY-App FuNPaY-App-v1.2.zip
৪) www/js/app.js খুলে SUPA_URL ও SUPA_KEY বসান (ধাপ ১ এর ৪)।
৫) টার্মিনালে:  git add -A && git commit -m "first" && git push
৬) GitHub এ Actions ট্যাবে বিল্ড চলবে (APK ~৬ মিনিট, OTA ~১ মিনিট)।
৭) শেষ হলে ফোনের ব্রাউজারে এই লিংক খুলে APK নামিয়ে ইনস্টল করুন (বন্ধুদেরও এই লিংক দিন):
     https://raw.githubusercontent.com/আপনার-ইউজারনেম/রিপোর-নাম/apk/FuNPaY.apk
   (প্লে প্রোটেক্ট/অজানা সোর্স অনুমতি চাইলে দিন)
(Claude Code ব্যবহার করলে সেখান থেকেও এই ফাইলগুলো রিপোতে পুশ করানো যায়।)

আপডেট দেওয়া: GitHub এ (ব্রাউজারে ফাইল এডিট করে, বা Codespace থেকে) কোড বদলে commit করুন। আর কিছু করতে হবে না।

ধাপ ৩) এজেন্ট বানানো
--------------------
ওই ব্যক্তি আগে অ্যাপে নিজের নম্বরে অ্যাকাউন্ট খুলবেন। তারপর Supabase SQL Editor এ:
     update public.profiles set role = 'agent' where phone = '01XXXXXXXXX';

PIN ও আনলক
-----------
PIN ৬ ডিজিটের। প্রথমবার লগইনের পর অ্যাপ জিজ্ঞেস করবে ফিঙ্গারপ্রিন্ট বা ফোনের স্ক্রিন লক (প্যাটার্ন/পিন) দিয়ে আনলক চালু করবেন কিনা।
চালু করলে পরের বার অ্যাপ খুললেই আঙুলের ছাপ/ফোন লক চাইবে, PIN কিপ্যাডও থাকবে। "আমার FuNPaY" পেজ থেকে চালু/বন্ধ করা যায়।
১ মিনিটের বেশি ব্যাকগ্রাউন্ডে থাকলে অ্যাপ নিজে লক হয়।

আসল টাকার আগে অবশ্যই পড়ুন
---------------------------
এখন অ্যাপে নতুন অ্যাকাউন্টে ৫০০০ টাকা ফ্রি আর "অ্যাড মানি" দিয়ে বিনা পয়সায় টাকা যোগ হয়। এগুলো আসল টাকা নয়।
তাই www/js/app.js এ TEST_MODE = true আছে, যা "টেস্ট ভার্সন" লেখা ও ক্যাশ আউটের সতর্কতা দেখায়। কারণ এজেন্টরা আসল নগদ টাকা দিয়ে দিলে সেটা সরাসরি প্রতারণা হয়ে যাবে।
আসল টাকায় যেতে হলে বাংলাদেশ ব্যাংকের লাইসেন্স (PSP/MFS) বা লাইসেন্সপ্রাপ্ত পেমেন্ট পার্টনার লাগে। তখন backend/go-live.sql চালিয়ে ফ্রি টাকার সব পথ বন্ধ করে TEST_MODE = false করবেন।

সমস্যা হলে
-----------
- "ব্যাকএন্ড সেট করা নেই": SUPA_URL / SUPA_KEY বসাননি।
- "Confirm email বন্ধ করুন": ধাপ ১ এর ২ নম্বর করা হয়নি।
- ইমেইল এরর: app.js এ EMAIL_DOMAIN এ নিজের কোনো আসল ডোমেইন বসান (কাউকে ইমেইল যায় না)।
- আপডেট আসছে না: Actions ট্যাবে "ota" জব সবুজ কিনা দেখুন, আর repository Public কিনা দেখুন।
